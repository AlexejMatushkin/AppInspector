# App Inspector

**Современный инспектор установленных приложений для Android 7.0+**

Полностью рабочий, чистый и красивый инструмент для просмотра списка приложений с подробной информацией: название, версия, пакет, SHA-1 хэш APK и кнопка запуска.

| Список приложений                          | Детальная информация                           |
|--------------------------------------------------|-----------------------------------------------------|
| ![Список](screenshots/list.png?raw=true)        | ![Детали](screenshots/details.png?raw=true)         |

## Функции

- Отображение всех установленных приложений (включая системные)
- Детальная информация о приложении:
    - Название
    - Версия
    - Имя пакета
    - SHA-1 контрольная сумма APK-файла
- Кнопка «Открыть приложение»
- Навигация со стрелкой назад и иконкой приложения в тулбаре
- Современный Material Design 3
- Edge-to-edge (контент под статусбаром и навигационной панелью)
- Полностью на Kotlin

## Технологии

- **Kotlin** — 100%
- **Jetpack Navigation Component**
- **ViewModel + LiveData**
- **View Binding**
- **Material 3** (`com.google.android.material:material:1.13.0+`)
- **minSdk 24** — Android 7.0 Nougat и выше

> Работает идеально на Android 7.0 → 15

1. Склонировать репозиторий
2. Открыть в Android Studio
